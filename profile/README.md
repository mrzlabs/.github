# MRZ Labs

Soluciones de software para operación de negocios: **CRM, automatización y datos**. Colombia.

## Productos

| Producto | Qué resuelve | Stack |
|---|---|---|
| **Operux CRM** | CRM SaaS multi-tenant para barberías, spas y estudios de estilo y belleza | Next.js, TypeScript, Drizzle |
| **FloorUX** | POS + CRM para bares y discotecas: mesas, inventario, turnos y reportes | Next.js, Supabase |
| **TimeKeeper / TimeControl** | Control de jornada laboral con geocerca y QR, según la ley laboral colombiana | Google Apps Script, Sheets, Next.js |
| **Maylo** | Identidad y asistente operativo de la familia Operux | JavaScript, SVG |
| **Plataforma de afiliaciones** | Gestión de afiliaciones a EPS, ARL, pensión y caja de compensación | Astro, Supabase, Cloudflare Workers |

## Enfoque

- Arquitectura multi-tenant y roles desde el primer día.
- Automatización sobre Google Workspace cuando es suficiente, y plataformas propias cuando no.
- Documentación de decisiones junto al código y versiones etiquetadas.
