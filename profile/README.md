# MRZ Labs

Laboratorio personal de software abierto. Mi objetivo es **democratizar el acceso a los sistemas de desarrollo**: que construir un sistema no exija empezar de cero.

## Qué se publica aquí

| Repo | Para qué sirve |
|---|---|
| [tpl-mrz-gas-starter](https://github.com/mrzlabs/tpl-mrz-gas-starter) | Plantilla para arrancar un proyecto de Google Apps Script en minutos (clasp, ESLint 9, Prettier y CI) |
| [lib-mrz-gas-utils](https://github.com/mrzlabs/lib-mrz-gas-utils) | Utilidades sin dependencias: HTTP, reintentos con espera exponencial, logging y Google Sheets |
| [casos-de-estudio](https://github.com/mrzlabs/casos-de-estudio) | Diseño y decisiones técnicas de los proyectos del laboratorio |
| [learning-notes](https://github.com/mrzlabs/learning-notes) | Notas de desarrollo sobre seguridad, automatización y versionado |

## Proyectos donde se aplican estas ideas

| Proyecto | Qué explora | Stack |
|---|---|---|
| **Operux CRM** | CRM multi-tenant para negocios de estilo y belleza | Next.js, TypeScript, Drizzle |
| **FloorUX** | POS y CRM para bares con jerarquía de roles y aislamiento de datos | Next.js, Supabase |
| **TimeControl Suite** | Control de jornada laboral sobre Google Workspace | Google Apps Script, Sheets, Next.js |
| **Maylo** | Personaje reutilizable como identidad y asistente | JavaScript, SVG |

## Enfoque

- Arquitectura multi-tenant y roles desde el primer día.
- Automatización pragmática: Google Apps Script cuando basta, plataforma propia cuando hace falta.
- Documentación de decisiones junto al código y versiones etiquetadas.

> El código de los proyectos es privado; aquí se publica lo reutilizable y la documentación. Para conversar sobre una idea, escribe a través del perfil de [@amtz-dev](https://github.com/amtz-dev).
